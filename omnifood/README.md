# 🍽️ Omnifood

A modern landing page for a fictional AI-powered meal subscription service — built as the capstone project of my HTML & CSS course.

## Project Description

Omnifood is a conversion-focused landing page for a healthy meal delivery service. Built from scratch with semantic HTML and modern CSS, it covers real-world landing page structure: sticky navigation, hero section, social proof, step-by-step process, meal showcase, testimonials, pricing, and a lead-capture CTA.

## Project Status

✅ Desktop version complete  
⏳ Responsive design (in progress)  
⏳ Effects, optimizations & deployment (upcoming)

## Sections

- **Sticky Navigation** — logo, nav links, and "Try for free" CTA
- **Hero** — headline, dual CTAs, delivered-meals stat with customer avatars, and a hero image gallery
- **Featured In** — press logos (TechCrunch, Business Insider, The New York Times, Forbes, USA Today)
- **How It Works** — 3-step process with alternating text/image layout
- **Meals** — AI-selected meal cards (Japanese Gyozas, Avocado Salad) plus a "Works with any diet" list
- **Testimonials** — customer reviews with a gallery of food photography
- **Pricing** — Starter ($399) and Complete ($649) plans with feature comparisons, plus 4 key selling points
- **Call-to-Action** — "Get your first meal for free" lead-capture form
- **Footer** — contact info, account links, company links, resources, and social icons

## Built With

- HTML5
- CSS3

- Building a full, multi-section landing page from scratch

- Applying design principles — typography, spacing, color, visual hierarchy
