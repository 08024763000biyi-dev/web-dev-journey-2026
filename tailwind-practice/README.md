# 🎨 Tailwind CSS Practice

A dedicated practice environment built to learn and master Tailwind CSS utility classes.

## 📖 About

This folder was created as part of a 2-week sprint to learn Tailwind CSS before moving on to JavaScript. It uses Vite as the build tool and Node.js for package management. 

Instead of building a full project, this environment is used to translate vanilla CSS concepts into Tailwind utility classes.

## 🛠 Tech Stack

- HTML5
- Tailwind CSS
- Vite (Build Tool)
