# 🪑 Furniture Page

A design-focused landing page for a furniture brand, built to practice UI design — typography, colors, icons, and layout.

## Project Description

A simple landing page for a furniture brand, built as a design practice project. The goal was to apply my HTML and CSS skills to create a page that looks and feels like a real website — focusing on design principles rather than just functionality.

## Design Focus

- **Typography** — font pairing, hierarchy, spacing
- **Color** — palette selection, contrast, mood
- **Icons** — clean, consistent iconography
- **Layout** — spacing, alignment, visual balance
- **White Space** — breathing room and visual rhythm
- **UI Details** — border radius, box shadows, hover states

## Built With

- HTML5
- CSS3

## What I Learned

- Understanding website personalities and how design communicates mood
- Applying the "ingredients" of a website: typography, color, icons, spacing, and UI details
- Using white space intentionally for clean, readable layouts
- Adding depth with border radius and box shadows
- Designing for real-world feel, not just function
- Building UI layouts that look intentional
